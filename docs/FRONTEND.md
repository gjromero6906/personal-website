# Frontend

React + Vite single-page app. Talks to the Express API in [`../server`](BACKEND.md) over `/api/*` (proxied to `localhost:8080` in dev by `vite.config.js`).

## Folder map

| Folder | Contents |
|---|---|
| `src/` | Application source code — see [frontend-src.md](frontend-src.md) |
| `src/components/` | One file per page section / reusable UI piece — see [frontend-src-components.md](frontend-src-components.md) |
| `src/data/` | Static, frontend-only data (no backend round-trip) — see [frontend-src-data.md](frontend-src-data.md) |
| `public/` | Static assets served as-is at the site root (images, favicon) — see [frontend-public.md](frontend-public.md) |
| `dist/` | Production build output, generated by `npm run build`. Not source — safe to delete and regenerate. |
| `node_modules/` | Installed dependencies. Not source. |
| `.agents/` | Editor/AI-agent skill definitions used by tooling. Not part of the shipped app. |

## Top-level files

- **`index.html`** — the HTML shell Vite injects the React bundle into. Loads `src/main.jsx` and the Orbitron Google Font used for headings.
- **`vite.config.js`** — dev server + build config; proxies `/api` requests to the Express server on port 8080 during local development (`npm run dev`).
- **`package.json` / `package-lock.json`** — dependencies (`react`, `react-dom`, `@supabase/supabase-js`) and scripts (`dev`, `build`, `preview`).

## Data flow

Components fetch data from the backend (`/api/projects`, `/api/skills`, `/api/titles`) — there's no direct database access from the frontend. `frontend/src/data/skillDefinitions.js` is the one exception: static content that only ever lives in the frontend.

See [BACKEND.md](BACKEND.md) for the API side of this.
